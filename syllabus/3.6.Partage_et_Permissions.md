# Partage de dossiers et permissions Active Directory

## 1. Introduction aux permissions

Dans Active Directory, la sécurité des ressources repose sur deux niveaux de permissions :

1. **Permissions NTFS** (système de fichiers)
   - S'appliquent localement sur le serveur
   - Plus granulaires et détaillées
   - Toujours actives, même en accès local

2. **Permissions de partage** (réseau)
   - S'appliquent lors de l'accès réseau
   - Plus simples (Lecture, Modification, Contrôle total)
   - Ne s'appliquent que via le réseau

> **Note importante** : Les permissions finales sont l'intersection des deux types. L'utilisateur obtient le niveau de permission le plus restrictif entre NTFS et partage.

## 2. Configuration d'un partage réseau

### 2.1. Création du partage

1. **Préparation**
   ```
   a. Créez un dossier : D:\Partages\Comptabilite
   b. Clic droit -> Propriétés -> Partage
   c. Partage avancé -> Cocher "Partager ce dossier"
   d. Nom du partage : Comptabilite$
   ```
   > Le $ à la fin rend le partage caché

2. **Permissions de partage de base**
   ```
   a. Autorisations -> Ajouter
   b. Sélectionnez les groupes AD (voir chapitre [3.5.5 Groupes AD](3.5.5.Groupes_AD.md)) :
      - "Comptabilite-Users" : Modification
      - "RH-Managers" : Lecture
   ```

### 2.2. Configuration des permissions NTFS

1. **Permissions de base**
   ```
   a. Propriétés -> Sécurité -> Modifier
   b. Ajoutez les groupes AD avec les permissions :
      - "Comptabilite-Users" : 
         * Lecture
         * Écriture
         * Modification
      - "RH-Managers" :
         * Lecture
         * Afficher le contenu du dossier
   ```

2. **Permissions avancées**
   ```
   a. Paramètres avancés -> Ajouter
   b. Sélectionner un principal (groupe AD)
   c. Appliquer sur : "Ce dossier, les sous-dossiers et fichiers"
   ```

## 3. Exercice pratique - Partage départemental

### 3.1. Création de la structure

1. **Préparation des dossiers**
   ```
   D:\Partages\
   ├── Comptabilite
   │   ├── Public
   │   └── Confidentiel
   └── RH
       ├── Public
       └── Personnel
   ```

2. **Création des groupes AD**
   ```powershell
   # Création des groupes de sécurité
   New-ADGroup -Name "Comptabilite-Users" -GroupScope Global
   New-ADGroup -Name "Comptabilite-Managers" -GroupScope Global
   New-ADGroup -Name "RH-Users" -GroupScope Global
   New-ADGroup -Name "RH-Managers" -GroupScope Global
   ```

### 3.2. Configuration des permissions

1. **Dossier Comptabilité**
   ```
   Public :
   - Comptabilite-Users : Modification
   - RH-Users : Lecture
   
   Confidentiel :
   - Comptabilite-Managers : Contrôle total
   - Comptabilite-Users : Lecture
   ```

2. **Dossier RH**
   ```
   Public :
   - Tous les utilisateurs du domaine : Lecture
   - RH-Users : Modification
   
   Personnel :
   - RH-Managers : Contrôle total
   ```

### 3.3. Test des permissions

1. **Vérification des accès**
   ```
   a. Connectez-vous avec un compte utilisateur standard
   b. Tentez d'accéder aux différents dossiers
   c. Vérifiez que les restrictions fonctionnent
   ```

2. **Dépannage courant**
   ```
   a. Vérifiez l'appartenance aux groupes :
      Get-ADPrincipalGroupMembership "utilisateur"
   
   b. Testez le chemin réseau :
      \\serveur\partage\dossier
   
   c. Vérifiez les journaux d'événements
   ```

## 4. Bonnes pratiques

1. **Structure des dossiers**
   - Organisez par département
   - Séparez public/privé
   - Utilisez des noms clairs

2. **Groupes de sécurité**
   - Créez des groupes par fonction
   - Évitez les permissions utilisateur directes
   - Documentez les groupes

3. **Permissions**
   - Appliquez le principe du moindre privilège
   - Héritez les permissions quand possible
   - Évitez les permissions explicites "Refuser"

## 5. Exercice final - Migration de données

### 5.1. Scénario
Le service comptabilité doit migrer ses données vers un nouveau partage avec une structure améliorée.

1. **Création de la structure**
   ```
   D:\Partages\Comptabilite_V2\
   ├── _Archives
   ├── Clients
   │   ├── Actifs
   │   └── Inactifs
   ├── Factures
   │   ├── Emissions
   │   └── Receptions
   └── Rapports
   ```

2. **Configuration des permissions**
   ```
   a. Créez de nouveaux groupes AD :
      - COMPTA-ArchivesRO (lecture seule archives)
      - COMPTA-FacturesRW (modification factures)
      - COMPTA-RapportsRW (modification rapports)
   
   b. Configurez les permissions NTFS et partage
   
   c. Migrez les données
   ```

3. **Validation**
   ```
   a. Testez tous les accès
   b. Vérifiez la copie des données
   c. Validez avec les utilisateurs
   ```
