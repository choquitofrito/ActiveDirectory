# Group Policy Objects (GPOs)

## 1. Introduction aux GPOs

Les stratégies de groupe (GPOs) permettent de configurer et de contrôler les paramètres des utilisateurs et des ordinateurs dans Active Directory.

## 2. Configuration des GPOs pour notre laboratoire

### 2.1. Préparation

1. Ouvrez la console GPMC :
   ```
   Server Manager -> Tools -> Group Policy Management
   ```

2. Vérifiez la présence des GPOs par défaut :
   - Default Domain Policy
   - Default Domain Controllers Policy

### 2.2. Création des GPOs de base

1. GPO pour les clients :
   ```
   Nom : Clients-Security-Policy
   Lien : OU=Clients,OU=Computers,DC=computerelectronics,DC=be
   ```
   Paramètres :
   - Désactiver l'accès au registre
   - Activer le pare-feu Windows
   - Désactiver l'exécution de scripts non signés

2. GPO pour les utilisateurs standard :
   ```
   Nom : Standard-Users-Restrictions
   Lien : OU=Standard Users,OU=Users,DC=computerelectronics,DC=be
   ```
   Paramètres :
   - Masquer le panneau de configuration
   - Désactiver l'accès au cmd
   - Restreindre l'accès aux dossiers système

## 3. Exercices Pratiques

### 3.1. Configuration des stratégies

1. Configuration de Clients-Security-Policy :
   ```
   Computer Configuration
   ├── Policies
   ├── Windows Settings
   │   ├── Security Settings
   │   └── Windows Firewall
   └── Administrative Templates
       ├── System
       └── Windows Components
   ```

2. Configuration de Standard-Users-Restrictions :
   ```
   User Configuration
   ├── Policies
   └── Administrative Templates
       ├── Control Panel
       └── System
   ```

### 3.2. Tests et validation

1. Mise à jour des stratégies :
   ```powershell
   # Sur le client
   gpupdate /force
   ```

2. Vérification de l'application :
   ```powershell
   # Vérification des GPOs appliquées
   gpresult /r
   # Rapport détaillé
   gpresult /h c:\gpo_report.html
   ```

## 4. Dépannage des GPOs

1. Vérification de la réplication :
   ```powershell
   dcdiag /test:replications
   ```

2. Vérification des liens GPO :
   - Utilisez GPMC
   - Vérifiez l'ordre de traitement
   - Contrôlez les filtres de sécurité

3. Journal des événements :
   - Vérifiez les journaux d'application et système
   - Recherchez les événements liés aux GPOs
