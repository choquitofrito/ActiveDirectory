# Gestion des comptes utilisateurs

## 1. Introduction

La gestion des comptes utilisateurs est une tâche fondamentale dans Active Directory. Elle permet de :
- Contrôler l'accès aux ressources
- Appliquer des stratégies de sécurité
- Suivre l'utilisation des ressources

> **Note** : Pour la gestion des groupes et des permissions associées, consultez le chapitre [3.5.5 Groupes AD](3.5.5.Groupes_AD.md).

## 2. Création de comptes utilisateurs

### 2.1. Méthodes de création

1. **Interface graphique (ADUC)**
   ```
   a. Ouvrez 'Utilisateurs et ordinateurs Active Directory'
   b. Cliquez-droit sur l'OU cible -> Nouveau -> Utilisateur
   c. Remplissez les informations de base :
      - Prénom
      - Nom
      - Nom d'ouverture de session
      - Mot de passe initial
   ```

2. **PowerShell**
   ```powershell
   # Création d'un nouvel utilisateur
   New-ADUser -Name "Jean Dupont" `
              -GivenName "Jean" `
              -Surname "Dupont" `
              -SamAccountName "jdupont" `
              -UserPrincipalName "jdupont@computerelectronics.be" `
              -Path "OU=Comptabilite,OU=Users,DC=computerelectronics,DC=be" `
              -AccountPassword (ConvertTo-SecureString "Password1" -AsPlainText -Force) `
              -Enabled $true
   ```

### 2.2. Exercice pratique - Création d'utilisateurs

**Scénario** : Créer des comptes pour les nouveaux employés

1. **Création manuelle**
   ```
   Créez un compte pour Marie Martin (Comptabilité) :
   - Prénom : Marie
   - Nom : Martin
   - Login : mmartin
   - Email : mmartin@computerelectronics.be
   ```

2. **Création en masse (PowerShell)**
   ```powershell
   # Importer la liste depuis un CSV
   $Users = Import-Csv -Path "C:\nouveaux_employes.csv"
   
   foreach ($User in $Users) {
       New-ADUser -Name $User.Name `
                 -GivenName $User.FirstName `
                 -Surname $User.LastName `
                 -SamAccountName $User.Login `
                 -Department $User.Department `
                 -Path $User.OU `
                 -AccountPassword (ConvertTo-SecureString $User.Password -AsPlainText -Force) `
                 -Enabled $true
   }
   ```

## 3. Gestion des comptes

### 3.1. Propriétés importantes

1. **Informations de base**
   - Nom complet
   - Login (SamAccountName)
   - Email
   - Description

2. **Sécurité**
   - Mot de passe
   - État du compte (activé/désactivé)
   - Heures de connexion autorisées
   - Stations de travail autorisées

3. **Organisation**
   - Département
   - Titre
   - Manager

### 3.2. Exercice pratique - Modification de comptes

1. **Modification via l'interface**
   ```
   Pour Marie Martin :
   a. Ajoutez son numéro de téléphone
   b. Définissez son manager
   c. Limitez ses heures de connexion (8h-18h)
   ```

2. **Modification via PowerShell**
   ```powershell
   # Modification d'un utilisateur
   Set-ADUser -Identity "mmartin" `
              -OfficePhone "02123456" `
              -Manager "CN=Jean Dupont,OU=Comptabilite,OU=Users,DC=computerelectronics,DC=be" `
              -Replace @{logonHours = $newLogonHours}
   ```

## 4. Bonnes pratiques

1. **Nommage des comptes**
   - Convention cohérente (ex: première lettre prénom + nom)
   - Éviter les caractères spéciaux
   - Pas d'espaces dans les logins

2. **Sécurité**
   - Mots de passe initiaux complexes
   - Changement obligatoire à la première connexion
   - Désactivation plutôt que suppression
   - Gestion des accès aux ressources (voir chapitre [3.6 Partage et Permissions](3.6.Partage_et_Permissions.md))

3. **Documentation**
   - Tenir un registre des créations/modifications
   - Documenter les procédures
   - Noter les exceptions aux règles standard

## 5. Exercice final - Gestion complète

**Scénario** : Gérer le cycle de vie d'un utilisateur

1. **Création**
   - Créer le compte selon les standards
   - Placer dans la bonne OU
   - Configurer les propriétés de base

2. **Modification**
   - Changement de département
   - Mise à jour des groupes
   - Ajustement des droits

3. **Désactivation**
   - Désactiver le compte
   - Sauvegarder les données
   - Documenter les actions

4. **Validation**
   ```powershell
   # Vérification du compte
   Get-ADUser -Identity "mmartin" -Properties *
   
   # Vérification des appartenances aux groupes
   Get-ADPrincipalGroupMembership "mmartin"
   ```
