# Gestion des Utilisateurs et des Ordinateurs

## 1. Introduction

### 1.1. Vue d'Ensemble

La gestion des utilisateurs et des ordinateurs est une tâche fondamentale dans Active Directory qui comprend :
- La création et maintenance des comptes
- L'intégration des postes de travail
- La gestion des groupes de sécurité
- L'application des stratégies

### 1.2. Objectifs Pédagogiques

À la fin de ce chapitre, vous serez capable de :
1. Configurer et maintenir les comptes utilisateurs
2. Intégrer des postes au domaine
3. Gérer les groupes de sécurité
4. Vérifier et dépanner les accès

## 2. Configuration Initiale

### 2.1. Vérification de l'Environnement

1. Vérifiez l'état du domaine :
   ```powershell
   dcdiag /v
   netdom query fsmo
   ```

2. Contrôlez la politique de mot de passe :
   ```powershell
   Get-ADDefaultDomainPasswordPolicy
   ```

## 2. Gestion des Ordinateurs

### 2.1. Préparation des Clients

1. Configuration des postes clients :
   - Premier client :
     ```
     Nom : ws-compta-01
     IP : 192.168.0.101
     DNS : 192.168.0.2
     ```
   - Second client :
     ```
     Nom : ws-rh-01
     IP : 192.168.0.102
     DNS : 192.168.0.2
     ```

2. Joindre les clients au domaine :
   ```powershell
   # Sur chaque client
   Add-Computer -DomainName computerelectronics.be -Restart
   ```

### 2.2. Vérification des Comptes Ordinateurs

1. Dans Utilisateurs et ordinateurs Active Directory :
   - Vérifiez que les ordinateurs apparaissent dans l'OU Clients
   - Contrôlez leurs propriétés

## 3. Gestion des Utilisateurs

### 3.1. Création des Comptes

1. Compte administrateur IT :
   ```powershell
   New-ADUser -Name "Admin IT" -SamAccountName "admin.it" `
              -Path "OU=IT,OU=Users,DC=computerelectronics,DC=be" `
              -AccountPassword (ConvertTo-SecureString "P@ssw0rd" -AsPlainText -Force) `
              -Enabled $true
   ```

2. Comptes utilisateurs standard :
   ```powershell
   # User1
   New-ADUser -Name "User1" -SamAccountName "user1" `
              -Path "OU=Standard Users,OU=Users,DC=computerelectronics,DC=be" `
              -AccountPassword (ConvertTo-SecureString "P@ssw0rd1" -AsPlainText -Force) `
              -Enabled $true

   # User2
   New-ADUser -Name "User2" -SamAccountName "user2" `
              -Path "OU=Standard Users,OU=Users,DC=computerelectronics,DC=be" `
              -AccountPassword (ConvertTo-SecureString "P@ssw0rd2" -AsPlainText -Force) `
              -Enabled $true
   ```

### 3.2. Gestion des Groupes

1. Création des groupes :
   ```powershell
   # Groupe IT
   New-ADGroup -Name "IT Staff" -GroupScope Global `
               -Path "OU=IT,OU=Users,DC=computerelectronics,DC=be"

   # Groupe Utilisateurs Standard
   New-ADGroup -Name "Standard Access" -GroupScope Global `
               -Path "OU=Standard Users,OU=Users,DC=computerelectronics,DC=be"
   ```

2. Ajout des membres :
   ```powershell
   Add-ADGroupMember -Identity "IT Staff" -Members "admin.it"
   Add-ADGroupMember -Identity "Standard Access" -Members "user1","user2"
   ```

## 4. Tests et Vérification

### 4.1. Tests de Connexion

1. Sur ws-compta-01 :
   - Connectez-vous avec user1
   - Vérifiez l'accès aux ressources

2. Sur ws-rh-01 :
   - Connectez-vous avec user2
   - Vérifiez l'accès aux ressources

### 4.2. Vérification des Droits

1. Vérifiez les appartenances aux groupes :
   ```powershell
   Get-ADPrincipalGroupMembership user1 | Select Name
   Get-ADPrincipalGroupMembership admin.it | Select Name
   ```

2. Testez les restrictions :
   - Accès au panneau de configuration
   - Exécution de commandes
   - Accès aux dossiers système
