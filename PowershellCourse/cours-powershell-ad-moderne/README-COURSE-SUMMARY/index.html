    🚀 Cours PowerShell AD Moderne 2025 - Résumé Complet

    📋 Vue d'Ensemble du Cours

    Ce cours transforme l'approche traditionnelle de PowerShell AD vers une méthode de survie professionnelle moderne

    📚 Structure Complète du Cours

    Module 1: Réalité 2025 (2h00)

    Objectif: Démystifier comment les admins travaillent vraiment Contenu: - Cercle d'honnêteté sur utilisation Google/IA - Démonstration live "Mon lundi typique" - Art de googler efficacement pour PowerShell AD - Exercices pratiques avec infrastructure maxtec.be

    Module 2: Survie Tickets (2h00)

    Objectif: Maîtriser les 10 commandes qui sauvent des carrières Contenu: - Diagnostic utilisateur bloqué - Recherche par critères partiels - Gestion groupes et permissions - Onboarding/offboarding sécurisé - Audit rapide des droits admin

    Module 3: IA comme Copilote (1h30)

    Objectif: Utiliser l'IA professionnellement et sécurisé Contenu: - Prompts précis avec exigences sécurité - Validation critique ligne par ligne - Templates prêts à utiliser - Détection de code dangereux avec IA - Adaptation environnement spécifique

    Module 4: Scripts Bomba Lab (2h00)

    Objectif: Détecter erreurs mortelles cachées Contenu: - Anatomie d'un script piégé - 3 scripts bombes éducatifs complets - Techniques de camouflage courantes - Analyse forensique d'erreurs - Versions sécurisées de référence

    Module 5: -WhatIf Religieux (1h30)

    Objectif: Ancrer -WhatIf dans l'ADN professionnel Contenu: - Hall of fame des désastres sans -WhatIf - Simulacre "Vendredi 17h - Le piège" - Certification réflexes -WhatIf - Gestion pression et urgence - Exceptions inexistantes à la règle

    Module 6: Kit d'Urgence (1h00)

    Objectif: Procedures structurées en situation de crise Contenu: - 10 étapes de survie "Break Glass" - Simulation crise en live avec classe - Scripts de diagnostic et récupération d'urgence - Checklist plastifiée pour situations critiques - Communication efficace en crise

    🏗️ Infrastructure maxtec.be Utilisée

    Configuration Laboratoire

    Domaine: maxtec.be
DC: dns1.maxtec.be (192.168.0.2)
Base DN: DC=maxtec,DC=be

Structure OU:
OU=EU,DC=maxtec,DC=be
├── OU=IT (Ivan, Ines, Irene)
├── OU=Ventes (Victor, Vanessa, Valeria, Valentin)
├── OU=RH (Rene, Rebecca, Richard)
└── OU=Compta (Charles, Cindy, Charlotte)

Groupes: GG-EU-[Dept]-[Users/Admins]

    Utilisateurs Types Réalistes

    • Noms hispaniques avec accents possibles
    • Départements reflétant structure entreprise réelle
    • Permissions hiérarchiques cohérentes
    • Historique de connexions et changements réaliste
